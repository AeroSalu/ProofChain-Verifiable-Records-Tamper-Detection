Sign in

Registering, confirming and sealing records needs a staff account, so that each confirmation names the person who made it. Checking a document does not: the Verify page is open to everyone.

Accounts are created on the machine that runs the registry, with python -m proofchain.registry.staff add <username>. There is no sign-up page.
